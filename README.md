# Digital Wallet Application

A web-based Digital Wallet Application developed using Python Flask, SQLite, HTML, and CSS.

## Live Demo

https://digital-wallet-application.onrender.com

---

## Features

- User Registration
- User Login Authentication
- Secure Session Management
- Check Wallet Balance
- Add Money
- Withdraw Money
- Transaction History
- Analytics Dashboard
- Multi-User Support
- Logout Functionality

## Installation

Clone the repository:

```bash
git clone https://github.com/farheenmariam3-dotcom/Digital-Wallet-Application.git
```

Move into the project folder:

```bash
cd Digital-Wallet-Application
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
